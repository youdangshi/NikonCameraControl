# 妮妮

面向 Nikon Z30 的 Android 相机控制与本地修图应用。

妮妮把手机变成相机遥控器：通过相机 WiFi 热点、STA 局域网或 USB Type-C 连接 Nikon 相机，进行实时取景、参数调节、遥控拍摄、照片读取和本地修图。

> 当前为真机测试版。主要验证机型是 Nikon Z30 + Redmi M2011K2C（Android 13）。不同 Nikon 机型和固件可能返回不同的 PTP 属性，请以实际连接结果为准。

## 已实现功能

### 相机连接

- 相机 WiFi 热点直连：手机连接 Nikon 相机热点，默认地址 `192.168.1.1:15740`。
- STA 局域网连接：相机和手机连接同一网络，在 App 中输入相机 IP；按相机端模式选择 PC 控制或智能设备传输。
- USB Type-C：Android 手机作为 USB Host，通过 PTP over USB 控制相机。
- 连接档案：可保存多台相机和多种连接参数，下次直接从历史记录选择。
- 相机品牌识别：支持 Nikon 完整适配；Canon、Sony、Fujifilm 已接入识别和通用 PTP 能力边界，未实现厂商私有功能前会阻止不兼容命令。
- 连接状态与历史连接记录分开显示。
- 每种连接方式都有软件内教程和诊断日志。

### 实时取景与拍摄

- 手机查看相机实时画面，真机测试约 7–15 FPS。
- 实时取景默认锁定横屏，并完整显示相机画面。
- 监视器模式：保持屏幕常亮，取景断流或停止后自动尝试恢复连接。
- 右下角按钮在横屏和竖屏之间切换，不会裁切画面。
- 可直接调节曝光模式、ISO、快门、光圈、曝光补偿、白平衡、测光、对焦和驱动模式。
- 当前档位从相机读取，支持 `M / A / S / P / AUTO / U1 / U2 / U3`。
- 参数诊断记录操作码、响应码、耗时、原始字节，并在写入后从相机读回，区分“命令成功”和“实际生效”。
- 支持自动对焦和遥控拍照。
- 专业构图辅助：三分线、黄金分割、精密网格、中心构图、对角引导、水平仪。
- 构图线只覆盖相机实际画面区域，支持透明度调节。
- 人像姿势参考与构图辅助分离，默认不显示姿势骨架。

### 相机照片与修图

- 按 PTP 目录树读取相机存储卡，不再把 `DCIM` 当成照片。
- 支持 JPEG、MOV 等项目类型筛选。
- 自动读取缩略图；相机不支持标准缩略图接口时会回退读取原图或 EXIF 缩略图。
- 相机照片可以直接进入修图器。
- 修图页提供一键人像、风格强度、肤色、磨皮、淡斑、五官和基础调色。
- PS 基础模块按“光影 / 颜色 / 效果 / 曲线 / 混色”分组，支持纹理、去雾、降噪、可拖动五点曲线、实时 RGB 直方图和六色颜色混合。
- 局部蒙版支持径向和线性范围、羽化、反向，以及蒙版内曝光、对比度、饱和度和色温调整。
- 尼康云创模块支持导入 Nikon Flexible Color Picture Control（`.NP3`），映射优化校准、颜色混合、色彩分级和自定义曲线。
- 专业调色支持 Lift / Gamma / Gain 颜色轮和 Adobe Cube 3D LUT 导入。
- 提供风光、夜景、星空、建筑、美食、胶片、日系、黑白和电影等风格预设。
- 支持本地照片导入、AI 分析和修图建议。

### 实验模式

没有相机时，可以使用内置模拟相机体验完整流程：

1. 打开“相机”页面。
2. 选择“实验模式”。
3. 点击“启动实验”。
4. 进入实时取景、拍摄、相机照片和修图。

## 连接教程

### WiFi 热点

1. 相机开机，进入无线连接菜单。
2. 选择允许计算机控制或建立 WiFi 连接。
3. 手机连接相机热点，例如 `NIKON_Z_30_77128`。
4. 打开妮妮，进入“相机 → WiFi 热点”。
5. 地址填写 `192.168.1.1`，端口填写 `15740`，点击连接。

注意：相机热点可能没有互联网，这是正常现象。双 WiFi 手机可以同时保留家庭 WiFi。

### STA 局域网

1. 手机连接家庭或工作 WiFi。
2. 根据用途在相机无线菜单中选择“连接到电脑”或“发送到智能设备”。
3. 在相机屏幕查看相机 IP。
4. 打开妮妮，进入“相机 → STA 局域网”。
5. 输入相机 IP，并在 App 中选择与相机端一致的连接模式。
6. 端口保持 `15740`，点击连接。

手机和相机必须处于同一网段，路由器不能开启客户端隔离。

模式说明：

- `PC 控制`：相机端也要选择“连接到电脑”，用于实时取景、遥控拍摄和照片传输。
- `智能设备`：相机端选择“发送到智能设备/连接智能手机”，通常只用于浏览和传输照片，不发送取景、对焦或拍照命令。

早期真机测试中，相机处于智能设备传输模式时，发送取景或对焦命令会让 Z30 退出网络。妮妮现在会把这两种模式分开，避免模式不匹配时误触控制命令。

PC 控制连接使用 `Nikon PC` 作为 PTP/IP 客户端名称，并在进入取景前请求相机切换 `ChangeApplicationMode(1)`，退出取景后恢复文件传输模式。

### USB Type-C

1. 使用支持数据传输的 Type-C 线。
2. 相机开机，USB 模式设为 MTP 或 PTP。
3. 连接相机和手机。
4. 系统请求 USB 权限时选择允许。
5. 打开妮妮，进入“相机 → USB Type-C”，点击连接 USB。

纯充电线不会出现在 USB 设备列表中。连接异常时可以点击重新检测。

## 当前兼容范围

### Nikon

- 已在 Nikon Z30 上验证 USB、WiFi 热点、实时取景、参数读写、拍照和照片枚举。
- 其他 Nikon Z 系列机型可以尝试连接，但曝光属性、模式值和厂商操作码需要逐机型确认。

### 其他品牌

PTP/PTP-IP 的基础传输层是通用的，但实时取景、快门、对焦和参数控制大量依赖厂商私有协议。

- 佳能需要 Canon EOS PTP 扩展或 CCAPI 适配。
- Sony、富士等品牌同样需要单独实现品牌驱动。
- 当前版本不是“改成型号名就能控制所有相机”。

后续架构方向是：通用 PTP 核心 + Nikon / Canon / Sony 等品牌适配层。

## 从源码构建

环境要求：

- Node.js 20 或更高版本。
- JDK 21。
- Android SDK。

```bash
cd app
npm ci
npm run test:all
npx vite build
npx cap sync android
cd android
./gradlew assembleDebug
```

Windows 使用：

```powershell
cd app
npm ci
npm run test:all
npx vite build
npx cap sync android
cd android
.\gradlew.bat assembleDebug
```

APK 输出：

```text
app/android/app/build/outputs/apk/debug/app-debug.apk
```

## 自动化发布

`.github/workflows/android-release.yml` 会在 `main` 分支收到包含 `[release]` 的提交时：

1. 安装依赖。
2. 运行 PTP/IP、USB、假相机故障场景和跨品牌适配自检。
3. 构建 Web 资源和 Android APK。
4. 读取 `app/package.json` 中的版本号。
5. 创建 `v版本号` GitHub Release。
6. 上传 APK 附件。

也可以从 GitHub Actions 页面手动运行 `Build Android release`。

## 已知限制

- 当前主要面向 Nikon Z30，其他机型需要适配。
- 相机固件和拍摄模式会影响可写参数。
- 部分 Nikon 机型对快门、光圈和实时取景事件的处理不同。
- Nikon Z30 的 STA 智能设备模式只用于照片传输；需要实时取景时，相机端和 App 端都要选择 PC 控制模式。
- WiFi 模式需要相机处于支持 PTP/IP 遥控的菜单状态，SnapBridge 传图模式不等同于遥控模式。
- 当前安装包是 debug APK，适合测试，不适合正式分发。
