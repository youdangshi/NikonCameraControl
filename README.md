# 妮妮

面向 Android 的 Nikon 相机遥控、照片传输与本地修图应用。

妮妮通过 USB Type-C、相机 WiFi 热点或 STA 局域网连接相机，在手机上完成实时取景、曝光参数控制、自动对焦、遥控拍摄、相机照片读取和本地修图。项目重点解决 Nikon Z30 真机控制链路，并为后续多机型、多品牌适配建立独立协议层。

> 当前版本：`v1.11.0`
> <br>
> 真机验证设备：Nikon Z30 + Redmi M2011K2C（Android 13）
> <br>
> USB 实时取景实测：`30 FPS`

## 主要能力

### 相机连接

- USB Type-C：手机作为 USB Host，通过 PTP over USB 直连相机。
- 相机 WiFi 热点：手机连接相机创建的热点，使用 PTP/IP 通信，默认端口 `15740`。
- STA 局域网：相机和手机连接同一网络，支持 PC 控制和智能设备传图两种模式。
- 多连接档案：保存不同相机、IP、端口和连接模式，下次直接选择。
- 结构化诊断：记录连接状态、PTP 操作码、响应码、耗时、原始数据和参数写后读回。

### 实时取景与拍摄

- 实时取景显示相机 JPEG 视频流。
- 当前 USB 真机验证目标为 `30 FPS`，使用上一帧完成后立即请求下一帧的自适应循环。
- 默认横屏显示，可切换横竖屏，不强制裁切相机画面。
- 显示 RGB 与亮度直方图。
- 专业构图辅助：三分线、黄金分割、精密网格、中心构图、对角引导和水平仪。
- 直接调节曝光模式、ISO、快门、光圈、曝光补偿、白平衡、测光和驱动模式。
- 读取相机当前档位，支持 `M / A / S / P / AUTO / U1 / U2 / U3`。
- 自动对焦、触摸对焦和遥控拍摄。
- 监视器模式：保持屏幕常亮，并对取景断流执行恢复。

### 相机照片

- 按 PTP 目录树读取相机存储卡，不把目录当作照片。
- 支持 JPEG、MOV 等文件类型筛选。
- 读取缩略图和对象元数据。
- 相机照片可直接进入修图器。
- 连接档案与历史连接记录分离保存。

### 手机相机

- 直接调用 Android 系统相机使用手机镜头拍照。
- 支持前置和后置摄像头切换。
- 拍摄后自动保存到系统相册。
- 拍完可以直接进入妮妮修图器。
- 首页和本地照片页均提供手机拍照入口。

### 本地修图

- 基础调色：曝光、对比度、高光、阴影、白色、黑色、色温、色调、饱和度、自然饱和度、清晰度、纹理、去雾、降噪、锐化、暗角和颗粒。
- 专业曲线：`RGB / 红 / 绿 / 蓝` 四通道曲线。
- 曲线使用单调三次插值，避免普通样条常见的过冲和相邻色调震荡。
- 局部蒙版：径向渐变、线性渐变和可拖动画笔蒙版。
- 蒙版支持羽化、不透明度、反向，以及局部曝光、对比度、饱和度和色温。
- 编辑历史：撤销、重做，最多保留 40 个快照。
- 人像模块：一键人像、肤色、磨皮、淡斑、牙齿、唇色、五官和轮廓调整。
- 色彩轮：Lift / Gamma / Gain。
- Adobe Cube 3D LUT 导入和强度控制。
- Nikon Flexible Color Picture Control（`.NP3`）导入和近似预览。
- 风光、夜景、星空、建筑、桥梁、美食、胶片、日系、黑白和电影预设。

### AI 诊断

- 即使没有配置 API Key，也会先进行本地图像诊断。
- 分析平均亮度、动态范围、高光/暗部压缩、白平衡偏色、饱和度和边缘清晰度。
- 支持自动、人像、风光、夜景、星空、建筑、美食、街拍和胶片模式。
- 支持 OpenAI、DeepSeek 或其他 OpenAI 兼容接口。
- 视觉模型会检查主体、光线、构图、肤色、景深和题材。
- 模型输出经过 JSON 解析和参数白名单校验后才能进入修图器。
- 每条建议显示具体参数，可单独应用、一键全部应用，并可撤销。
- 内置 OpenAI、DeepSeek、硅基流动、阿里云百炼、火山方舟、Moonshot、智谱、OpenRouter、Groq、xAI、Mistral 和 Ollama 预设。
- 选择供应商后自动填写接口地址，只需输入 API Key。
- 可读取账号当前可用模型，自动过滤 embedding、语音和图像生成模型，并优先选择视觉模型。

## 连接方式

### USB Type-C

1. 使用支持数据传输的 Type-C 线连接相机和手机。
2. 相机开机，USB 模式设置为 MTP 或 PTP。
3. Android 请求访问相机时选择允许。
4. 打开妮妮，进入“相机 -> USB Type-C”。
5. 确认检测到 `Nikon 相机 · 0x04B0:0x0452`，点击“连接 USB”。

纯充电线不会出现在 USB 设备列表中。若设备检测不到，先检查数据线，再重新插拔相机和手机。

### 相机 WiFi 热点

1. 相机开机，进入无线连接菜单。
2. 选择允许计算机控制或建立 WiFi 连接。
3. 手机连接相机创建的热点，例如 `NIKON_Z_30_77128`。
4. 打开妮妮，进入“相机 -> WiFi 热点”。
5. 地址填写 `192.168.1.1`，端口填写 `15740`。

相机热点通常没有互联网，这是正常现象。双 WiFi 手机可以同时保留家庭网络。

### STA 局域网

1. 手机连接家庭或工作 WiFi。
2. 相机连接同一个网络。
3. 根据用途在相机端选择“连接到电脑”或“发送到智能设备”。
4. 在相机屏幕查看分配到的 IP 地址。
5. 在妮妮中填写相机 IP，并选择与相机端一致的连接模式。

- `PC 控制`：用于实时取景、遥控拍摄和照片传输。
- `智能设备`：仅用于照片浏览和传输，不发送控制命令。

手机和相机必须处于同一网段，路由器不能开启客户端隔离。

## 项目结构

```text
nikon-camera-control/
|-- app/
|   |-- src/                  React 界面、相机 API、修图引擎和协议层
|   |-- android/              Capacitor Android 工程与原生 USB 插件
|   |-- scripts/              协议、假相机、修图、机型与适配器测试
|   |-- release/              本地构建的测试 APK
|   `-- server.cjs            保留的本地服务端实现
|-- docs/                     发布说明、截图和项目文档
|-- .github/workflows/        GitHub Actions 自动构建与发布
`-- packages/                 早期架构蓝图
```

真正运行的 Android 应用位于 `app/`。

## 从源码构建

环境要求：

- Node.js 20 或更高版本。
- JDK 21。
- Android SDK。

```bash
cd app
npm ci
npm run test:all
npx vite build
npx cap sync android
cd android
./gradlew assembleDebug
```

Windows：

```powershell
cd app
npm ci
npm run test:all
npx vite build
npx cap sync android
cd android
.\gradlew.bat assembleDebug
```

APK 输出：

```text
app/android/app/build/outputs/apk/debug/app-debug.apk
```

## 自动化测试

`npm run test:all` 覆盖：

- PTP/IP 会话与数据阶段。
- USB PTP 容器和控制序列。
- Nikon 快门、光圈、ISO 和曝光补偿编码。
- 假相机参数写入、读回和故障场景。
- 曲线单调插值与图像引擎。
- Nikon 机型和固件字符串识别。
- 多品牌适配器操作码与未验证命令拦截。

GitHub Actions 会在 `main` 分支收到包含 `[release]` 的提交后构建 APK、创建版本标签并上传 Release 附件。也可以手动运行 `Build Android release`。

## 已知限制

- Nikon Z30 是当前唯一完整真机验证机型。
- USB 实时取景达到 `30 FPS`，WiFi 帧率受相机和网络环境影响。
- 相机固件和拍摄模式会影响可写参数。
- STA 智能设备模式只用于照片传输。
- 部分 Nikon 机型对快门、光圈、对象句柄和取景事件的处理不同。
- Canon、Sony、Fujifilm 尚未完成真机控制验证。
- 当前 APK 使用项目固定测试签名。

## 安全与隐私

- 相机通信直接发生在手机与相机之间。
- AI API Key 只保存在当前设备。
- 项目不上传个人照片和相机凭据。
- 仓库不提交 APK、构建产物、密钥、本机路径或个人照片。
- 不要在 Issue 或提交中粘贴 GitHub Token、相机密钥或私有照片。
