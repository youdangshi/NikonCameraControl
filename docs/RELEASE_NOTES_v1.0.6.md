# 妮妮 v1.0.6

这是面向 Nikon Z30 的 Android 测试版，安装包为 `Nini-1.0.6-debug.apk`。

## 本次重点

- 修复实时取景的启动、停止、重复点击和超时清理。
- USB Host 增加权限处理、连接会话清理、端点选择、分段读写和 Java 日志。
- 参数控制改用 Nikon Z30 PTP 属性编码，相机确认成功后才更新界面。
- 写入失败时显示 PTP 响应码，不再把界面误报为已修改。
- 增加 USB、相机 WiFi 热点和 STA 局域网连接说明入口。
- 增加协议自检，覆盖 PTP/IP、USB、Nikon 属性和值编码。

## 安装

1. 下载 `Nini-1.0.6-debug.apk`。
2. 在 Android 7.0 或更高版本手机上允许安装未知来源应用。
3. 安装后打开“妮妮”。

## 真机测试提示

- USB 模式需要 OTG 线直连相机和手机，相机 USB 模式设为 MTP/PTP。
- 相机不能同时连接电脑和手机。
- WiFi PTP/IP 需要相机无线模式设为“允许计算机控制”，不是 SnapBridge 传图模式。
- 当前仍是测试版，PTP 命令会因相机固件和拍摄模式不同而变化。
