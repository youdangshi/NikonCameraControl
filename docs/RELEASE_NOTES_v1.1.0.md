# 妮妮 v1.1.0

面向 Nikon Z30 的 Android 相机控制与本地修图测试版。

## 本次重点

- 整套 UI 重构为专业相机工具风格，统一顶部状态、底部导航、连接页、照片页、设置和修图页。
- 实时取景默认锁定横屏，画面按相机比例完整显示。
- 实时取景右下角按钮改为横屏 / 竖屏切换，不再使用裁切铺满模式。
- 新增专业构图辅助：三分线、黄金分割、精密网格、中心构图、对角引导、水平仪。
- 构图辅助只覆盖实际相机画面区域，并支持透明度调节。
- 人像姿势框线与构图辅助分离，默认不显示姿势骨架。
- 相机连接页和每项连接方式教程重新整理。
- 相机照片按 PTP 目录树递归读取，修复把 `DCIM` 当成照片的问题。
- 相机照片支持缩略图回退和照片 / 视频筛选。
- 修图页改为更接近主流人像软件的流程：一键人像、风格卡、整体强度、肤质和五官细调。
- 增强 USB PTP 会话恢复、实时取景、拍照、参数读写和相机 WiFi PTP/IP 连接。

## 已真机验证

- Nikon Z30 + Redmi M2011K2C。
- USB Type-C PTP 会话。
- 相机 WiFi 热点 PTP/IP 会话。
- 实时取景约 7–15 FPS。
- 模式读取，真机读回 `U1`、ISO 100、+0.0EV、自动白平衡和矩阵测光。
- 相机照片目录枚举及 JPEG / MOV 缩略图。
- 遥控拍照，停止取景后 `0x9207` 返回 `0x2001`。

## 安装

下载本次 Release 附件中的 `Nini-1.1.0-debug.apk`。

要求：

- Android 7.0 或更高版本。
- USB 模式需要支持 USB Host / OTG 的数据线。

## 已知限制

- 当前主要适配 Nikon Z30，其他尼康 Z 系列需要逐机型验证。
- 佳能、Sony、富士等品牌需要单独的品牌协议适配层。
- 当前为 debug APK，适合真机测试，不建议用于正式拍摄流程。
