# 妮妮 v1.1.1

本版本完善了无线连接的状态管理和错误提示。

## 更新内容

- 每种连接方式会独立记住最近一次成功使用的相机 IP 与端口。
- STA 局域网连接拆分为“PC 控制”和“智能设备传输”两种模式。
- PC 控制对应相机端“连接到电脑”，用于实时取景、遥控拍摄和照片传输。
- 智能设备模式只用于照片浏览和传输，避免向传输模式误发实时取景或对焦命令。
- 连接页补充两种 STA 模式的相机端设置步骤与限制说明。
- 增加相机 TCP 断开检测，实际掉线后 App 不再继续显示“就绪”。
- 保持相机热点和 USB Type-C 的实时取景、参数控制、拍照和照片读取流程不变。

## 安装

下载 `Nini-1.1.1-debug.apk` 并安装到 Android 手机。该包为真机测试版。
