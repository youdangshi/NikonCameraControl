# 妮妮 v1.11.0

本次更新重点修复相机热点无线连接稳定性，并补上更完整的相机参数读取和官方连接流程。

## 连接稳定性

- Android 原生 TCP 插件建立 PTP/IP 命令和事件连接前绑定 Wi-Fi 网络，减少相机热点无互联网时被系统切换到移动数据。
- PTP/IP 会话增加 30 秒心跳，自动恢复改为最多 5 次递增退避。
- 实时取景 WiFi 目标降至 10 FPS，USB 保持 30 FPS，并减少图片尺寸更新和直方图计算造成的重绘。

## 实时取景

- 参数栏支持向下隐藏，隐藏后可一键恢复。
- 横竖屏切换时画面和显示尺寸一起旋转，适配手机横屏取景。
- 取景界面保留构图辅助、人像姿势、直方图和监视器模式。

## 相机参数

- 新增自拍定时、自拍张数控制。
- 新增电池、图像尺寸、图像质量、焦距、闪光灯、日期时间、连拍张数、作者、版权等属性候选。
- 新增相机能力扫描，逐项读取相机返回的 GetDevicePropDesc，显示只读/可写、枚举或范围。

## 连接教程

- 新增官方连接流程弹窗，覆盖相机热点、手机热点、USB Type-C 和 SnapBridge 与 PTP/IP 的区别。
