# 妮妮 v1.12.0

本次更新加入应用内版本检查与安装，并修复快门量纲和自拍倒计时问题。

## 自动更新

- 设置页进入时自动检查 GitHub Releases 最新版本。
- 发现新版本后显示版本号和更新说明，可直接在应用内下载 APK。
- 下载完成后校验 Release 提供的 SHA256，并调起 Android 系统安装器。
- 首次安装需要授予安装未知应用权限，返回应用后会自动继续安装。

## 快门修复

- 修正 Nikon `0x500D` 快门属性单位。
- 快门原始值现在按 Nikon 的 100 微秒单位换算，不再把原始值直接显示为微秒。
- 设置快门时也使用相同单位写回相机，修复显示值正确但写入值错误的问题。
- AUTO、P、A、S 模式下会明确提示当前参数由相机控制，不再表现为点击无效。

## 自拍定时

- Z30 对 `0xD063/0xD0F5` 返回不支持时，不再伪造相机端 2/5/10/20 秒档位。
- 新增手机端应用内倒计时：关闭、2 秒、5 秒、10 秒、20 秒。
- 支持拍摄张数 1 至 9 张，倒计时显示在实时取景画面上。
- 相机端仍接收最终拍照命令，兼容当前已验证的 PTP/IP 路径。

## 实时取景

- 增加 5/10/15/30 FPS 帧率选择，连接后可在取景界面切换并记住设置。
- 连续读取错误增加退避和停止策略，避免 `PTP 0xa00b` 时持续高压轮询。
