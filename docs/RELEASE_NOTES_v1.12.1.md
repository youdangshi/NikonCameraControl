# 妮妮 v1.12.1

本次更新修复 Android 启动和实时取景稳定性，并加入峰值辅助对焦。

## 启动与实时取景

- Android 原生模式不再尝试连接网页端 `wss://localhost`，避免相机热点无互联网时反复失败。
- 移除在线字体依赖，首页冷启动由十余秒缩短到约 1 秒。
- 修复实时取景帧循环中的 `ReferenceError`，不会再停在最后一帧。
- 实测 WiFi 相机热点取景持续约 18–19 FPS，画面持续更新。

## 辅助对焦

- 新增峰值对焦：在实时画面上高亮锐利边缘，使用黄色峰值显示。
- 峰值对焦支持关闭、开启和三档边缘灵敏度调整，设置会保存在本机。
- 新增对焦模式显示，例如 `AF-S`、`AF-C`、`MF`。
- 新增镜头焦距显示，按 Nikon `0x5008` 的百分之一毫米量纲换算。
- 点击实时画面执行 AF 后，会显示“对焦中”“AF 锁定”或“AF 失败”。
