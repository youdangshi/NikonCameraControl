# 妮妮 v1.2.0

本版本加入 Photoshop 思路的基础修图模块，并完善无线连接模式。

## 更新内容

- 修图器新增 `PS 基础` 分组，包含 Light、Color、Effects、Curve、Mix。
- 新增纹理、去雾、降噪，以及黑色、阴影、中间调、高光、白色可拖动五点曲线。
- 预览区新增实时 RGB / 亮度直方图，曲线面板内也提供紧凑直方图参考。
- 新增红、橙、黄、绿、蓝、紫六色混合，可单独调整色相、饱和度和明度。
- STA 局域网拆分为 `PC 控制` 和 `智能设备`，需要与相机端连接模式保持一致。
- 增加相机连接断开检测，真实掉线后不再继续显示“就绪”。

## 安装

下载 `Nini-1.2.0-debug.apk` 并安装到 Android 手机。该包为真机测试版。
