# 妮妮 v1.4.0

本版本加入尼康云创预设导入和专业调色能力。

## 更新内容

- 新增“尼康云创”模块，可导入 Nikon Flexible Color Picture Control（`.NP3`）。
- 解析并应用优化校准、颜色混合、色彩分级和自定义色调曲线。
- 新增 Lift / Gamma / Gain 颜色轮。
- 新增 Adobe Cube 3D LUT 导入、强度控制和移除。
- 颜色混合扩展到红、橙、黄、绿、青、蓝、紫、洋红八色。
- 保留实时 RGB 直方图、五点曲线、径向和线性蒙版。

## 安装

下载 `Nini-1.4.0-debug.apk` 并安装到 Android 手机。该包为真机测试版。
