# 妮妮 v1.4.3

本版本加入参数诊断和假相机自检，用于定位相机参数读不到、写不进或写入后不生效的问题。

## 更新内容

- 参数读写会记录 PTP 操作码、响应码、原始字节、耗时和连接方式。
- 写入参数后自动从相机读回，区分“写入成功”与“相机实际生效”。
- 参数面板新增可展开的“参数诊断”，保留最近 50 条记录，可直接清空。
- 新增可配置假相机，支持测试错误响应、超时、拒绝写入和写入后不生效。
- `npm run test:all` 同时运行 PTP/IP、USB 和参数故障场景测试。
- 界面版本更新为 `1.4.3`。

## 安装

下载 `Nini-1.4.3-debug.apk` 并安装到 Android 手机。该包为真机测试版。
