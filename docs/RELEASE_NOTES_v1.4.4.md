# 妮妮 v1.4.4

本版本扩展多相机连接管理和手机监视器模式。

## 更新内容

- 新增相机品牌适配层，可识别 Nikon、Canon、Sony、Fujifilm 和通用 PTP。
- Nikon 保留实时取景、自动对焦、遥控拍摄和厂商属性完整能力。
- 其他品牌只开放已经实现的通用 PTP 能力；取景、对焦、快门等私有能力未适配前会主动阻止发送。
- 新增多相机连接档案，可保存、选择和删除 WiFi 热点、STA 局域网及 USB 参数。
- 新增监视器模式：屏幕保持常亮，取景停止或超过 5 秒没有新画面时自动重连。
- 补齐 `1/8000` 至 `1/32000` 高速快门档位，修复相机返回高速快门时界面显示 `--`。
- 连接页新增品牌选择和“实验功能”提示，避免把未验证品牌误报为完整支持。
- 自动化测试新增 Canon、Sony 通用 PTP 仿真读写和 Nikon 私有命令隔离测试。

## 安装

下载 `Nini-1.4.4-debug.apk` 并安装到 Android 手机。该包为真机测试版。
