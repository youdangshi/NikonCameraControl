# 妮妮 v1.4.5

本版本修复 Nikon 快门值单位错误。

## 修复内容

- Nikon PTP `ExposureTime (0x500D)` 的单位修正为 `100 微秒`，与相机显示一致。
- 修复相机显示 `1/40`、应用却显示 `1/4000` 的问题。
- 快门读取和写入都使用同一套 Nikon 单位换算，避免界面值正确但写回相机错误。
- 增加 `1/40` 快门编码和解码回归测试。
- 取景界面新增实时 RGB/亮度直方图，默认显示并可关闭。
- 底部常显模式、快门、ISO、光圈，可直接用 `− / +` 调节，并每 3 秒同步相机状态。
- 新增 `GetDevicePropDesc (0x1014)` 解析，优先读取相机实际支持的 ISO、快门和光圈档位。
- 参数面板显示相机报告的档位数量与范围。
- 检测到相机处于 `U1/U2/U3` 时，如果相机拒绝远程曝光调整，会明确提示切到 `M/A/S/P`。

## 安装

下载 `Nini-1.4.5-debug.apk` 并安装到 Android 手机。该包为真机测试版。
