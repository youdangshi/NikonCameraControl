# 妮妮 v1.4.7

本次更新集中处理手机端相机会话稳定性，为后续修图工作流和其他品牌适配打基础。

## 稳定性

- 相机连接日志改为结构化记录，包含时间、级别、传输方式、品牌和当前模式。
- PTP/IP 会话意外断开时自动恢复连接，最多重试两次，每次间隔不同，避免紧密重连冲击相机。
- 用户主动断开时会取消自动恢复，不会出现“刚断开又被连回”。
- USB 会话断开时不会尝试后台伪造重新插拔，而是明确提示重新连接数据线。
- 顶部连接状态新增“恢复连接”状态。

## 诊断导出

- 连接页支持复制结构化日志。
- Android 原生环境优先调用系统分享面板导出完整 JSON 诊断包。
- 诊断包包含会话状态、连接请求、普通事件和最近 50 条 PTP 属性读写记录。
