# 妮妮 v1.6.0

本次更新提升真机取景性能，并开始按 Nikon 机型分别管理能力。

## 实时取景性能

- 移除每帧固定等待 `65ms` 的实现，改为上一帧完成后立即请求下一帧，目标间隔 `33ms`。
- 取景画面改为直接更新图片元素，不再每帧触发整个 React 页面重渲染。
- USB 真机测得实时取景由约 `11 FPS` 提升到 `30 FPS`。
- FPS 统计、直方图、构图线和参数快捷控制保持工作。

## Nikon 机型能力

- 新增 Nikon Z 系列能力表：Z30、Z50、Zfc、Z6II、Z7II、Z8、Z9。
- Z30 标记为唯一已真机验证机型，实时取景上限 `30 FPS`。
- 其他 Z 系列标记为实验适配，默认按保守参数运行，不主动发送未验证的扩展命令。
- 从 PTP `DeviceInfo` 中提取机型和固件字符串，首次连接即可识别实际型号。
- 设置页新增 Nikon 机型能力列表和适配状态说明。
