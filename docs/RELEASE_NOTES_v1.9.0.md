# 妮妮 v1.9.0

本次更新重构 AI 修图模块，从“返回一段文字”升级为本地诊断、结构化视觉分析和可执行修图参数。

## 本地图像诊断

- 无需 API Key 也能分析照片。
- 统计平均亮度、黑场/白场、动态范围、高光溢出、暗部压缩、RGB 色偏、平均饱和度和边缘清晰度。
- 根据直方图给出保守的曝光、对比度、高光、阴影、白平衡、饱和度和降噪建议。

## 结构化视觉分析

- 支持自动、人像、风光、夜景、星空、建筑、美食、街拍和胶片模式。
- 支持 OpenAI、DeepSeek 和 OpenAI 兼容接口。
- 自动判断模型是否支持视觉输入；文本模型只使用本地统计，不会错误发送图片。
- 视觉输入最长边压缩到 1280 像素，降低流量和时延。
- 使用严格 JSON 结构输出场景、评分、问题、构图、人像肤色和修图建议。
- 模型返回值经过参数白名单、范围限制和非法字段过滤后才能应用。

## 修图器集成

- 修图器新增“AI 诊断”标签页。
- 显示曝光、色彩、构图、清晰度评分。
- 问题按严重程度展示，并附带本地测量数据。
- 每个建议显示具体调整参数，可单独应用或一键全部应用。
- 所有 AI 调整进入编辑历史，可撤销和重做。
- 本地照片页可直接分析，并把建议带入修图器。
